# סקירת שווקים — אתר מחקר כללי (סטטי, עברית, RTL)

אתר HTML סטטי ואינטראקטיבי (Plotly) לסקירת שווקי מניות לפי מדינה: מדד מוביל, פילוח סקטורים לפי שווי שוק, פירוט לכל סקטור וגרף השוואה של כל הסקטורים מול השוק. האתר מיועד למחקר כללי בלבד ואינו מכיל המלצות או תחזיות.

## האתר
כתובת: **https://elchananh.github.io/markets/** — אתר סטטי (GitHub Pages) שמותאם לאייפון ולמחשב, ועובד גם כאפליקציית web (PWA).

**התקנה באייפון:** לפתוח את הכתובת ב-Safari ← כפתור השיתוף ← "הוספה למסך הבית". האפליקציה נפתחת במסך מלא; המעטפת והשוק האחרון שנצפה נשמרים במכשיר ומוצגים גם בלי חיבור (עם סימון "עותק שמור במכשיר").

## קבצים
| קובץ | תיאור |
|---|---|
| `index.html` | הדף הראשי. טוען רק את `data/<שוק>.json` של השוק שנבחר. |
| `manifest.webmanifest`, `sw.js`, `icons/` | PWA: מניפסט, Service Worker (מטמון למעטפת ולנתוני השוק האחרון), אייקונים. |
| `assets/` | `app.js` (רינדור ורענון חי), `style.css` (עיצוב בהיר, מותאם מובייל), `plotly-basic.min.js` (Plotly 2.35.2, חבילה חלקית: scatter/bar/pie). |
| `data/` | `<שוק>.json` לכל שוק (מתחת ל-500KB כל אחד) ו-`markets.json` (רשימת השווקים). |
| `update_data.py` | רענון הנתונים (Python 3, yfinance, pandas, requests). היסטוריה: יומית ל-5 השנים האחרונות, שבועית לפני כן. |
| `check_site.py` | בדיקות: תקינות נתונים וגדלים, סריקת פרטיות, כרום headless בתצוגת אייפון (390×844) ובמחשב, בדיקת מצב לא מקוון. |
| `tools/privacy_scan.py` | שער פרטיות: נכשל על כל מידע אישי/פרטי (מיילים, טלפונים, טוקנים, נתיבים מקומיים ועוד) בקבצים, באתר המפורסם ובהיסטוריית git. |
| `config/markets.py` | הגדרת השווקים: מדד, קרן גיבוי, קרנות סל, מקור פילוח הסקטורים, קרנות אזוריות. |
| `.github/workflows/` | `refresh.yml` — רענון נתונים יומי (21:30 UTC, ימי ב'–ו' לפי UTC, אחרי סגירת וול סטריט) + commit ופריסה; `pages.yml` — פריסה ל-GitHub Pages עם שער פרטיות. |

## שימוש מקומי
```bash
pip install -r requirements.txt
python3 update_data.py                  # כל השווקים
python3 update_data.py brazil japan     # שווקים נבחרים
python3 update_data.py --no-fundamentals  # מהיר: בלי שווי שוק/מכפיל/דיבידנד למניות
python3 update_data.py --build-only     # רק דחיסה/בנייה מחדש של קבצי ה-JSON
python3 -m http.server 8000             # ואז http://localhost:8000/
python3 check_site.py                   # בדיקות + צילומי מסך (תיקיית screenshots/, לא נשמרת ב-git)
python3 check_site.py --url https://elchananh.github.io/markets/ --markets brazil,usa   # בדיקת האתר החי
```
קישור ישיר לשוק וטווח: `#m=japan&r=5Y` (טווחים: 1M, YTD, 1Y, 3Y, 5Y, MAX).

## פריסה (GitHub Pages)
* Settings ← Pages ← Source: **GitHub Actions**. הפריסה רצה בכל push ל-main ואחרי כל רענון נתונים.
* מתפרסמים רק קבצי האתר (`index.html`, `manifest.webmanifest`, `sw.js`, `assets/`, `icons/`, `data/*.json`) — לא קוד הסקריפטים, לא README ולא `.git`.
* לפני הפריסה רץ `tools/privacy_scan.py --site _site --history`; כל ממצא מכשיל את הפריסה. דפוסים פרטיים נוספים נקראים מה-secret ‏`PRIVACY_PATTERNS` (ולא נשמרים במאגר); בלעדיו השער נכשל.

## רענון חי בכל פתיחה

בכל פתיחה של הדף הדפדפן מושך מחירים עדכניים ישירות, בלי שרת, בלי מפתח ובלי פרוקסי:

- **מקור:** CNBC — `ts-api.cnbc.com/harmony/app/charts/1M.json` (כשנה של סגירות יומיות) ו-`quote.cnbc.com/.../restQuote` (מחיר אחרון, עשוי להיות מושהה). שני השירותים מחזירים `Access-Control-Allow-Origin: *`. אלה ממשקים לא-רשמיים ולא מתועדים שהאתר של CNBC עצמו משתמש בהם — הם עלולים להשתנות או להפסיק לעבוד בלי הודעה, והשימוש כפוף לתנאי השימוש של CNBC.
- **מה מתרענן:** המדד המוביל, קרנות הסל, שערי החליפין, קרנות הסקטור האמריקאיות (XL*), הסדרות הדולריות המחושבות (מדד ÷ מט"ח), טבלאות התשואה והגרפים המנורמלים.
- **שיטת חיבור:** ההיסטוריה המוטמעת (Yahoo Finance) מחוברת לסדרה החיה בנקודת עיגון משותפת; אם היחס החציוני בין המקורות בעשרת הימים המשותפים האחרונים חורג מ-3% (6% במט"ח) — הרענון נדחה ומוצגים הנתונים המוטמעים.
- **מה נשאר סטטי:** פילוח הסקטורים והרכיבים (עם תאריך "נכון ל-"), סלי הסקטור המחושבים (פרוקסי), נתוני המניות, וסדרות שאין להן מקבילה ב-CNBC (‎^MERV, ICOLCAP.CL‎). אלה מתעדכנים רק בהרצת `update_data.py`.
- **חיווי:** פס בראש הדף — "עודכן חי ב-<שעה> (שעון ישראל)" + המקור, או "נתונים נכון ל-<תאריך>, רענון חי נכשל" (ללא חיבור / חסימה). בעמודת "עדכון" בטבלת התשואות: "חי · תאריך" או "מוטמע".
- **אם CNBC יפסיק לעבוד:** הדף ממשיך להציג את הנתונים מהרענון היומי (GitHub Actions).

## מקורות
* **מחירים, מדדים, שערי חליפין** — Yahoo Finance דרך yfinance (מחירי סגירה מותאמים). כשמדד לא זמין ב-Yahoo או שיש לו היסטוריה קצרה, מוצגת קרן סל מדינה ומסומנת בבירור "קרן סל ולא המדד".
* **פילוח סקטורים ורכיבים** — קובץ האחזקות הרשמי של קרן סל המדינה:
  * iShares (BlackRock): `https://www.ishares.com/us/products/<id>/<fund>/latest-holdings.csv` — משקל לפי שווי שוק, סיווג GICS. הכתובות מאותרות אוטומטית מתוך product screener של iShares.
  * Global X (ארגנטינה ARGT, קולומביה COLO, יוון GREK): קובץ האחזקות `assets.globalxetfs.com/funds/holdings/<fund>_full-holdings_<date>.csv` ופילוח GICS הרשמי מעמוד הקרן. שיוך כל מניה לסקטור (לרשימות ולפרוקסי) לפי Yahoo Finance — מסומן בדף.
* **ארה"ב** — גרפי הסקטורים הם קרנות SPDR Select Sector (XLK, XLF, …) ולא פרוקסי.
* **חשיפה בקרנות אזוריות** — EEM, ILF, AAXJ, ACWI (iShares): משקל מניות המדינה בקרן ומשקל הסקטור של המדינה בקרן.
* **שווי שוק / מכפיל רווח / תשואת דיבידנד** — Yahoo Finance quote summary (נשמר במטמון עד 3 ימים).

האתר אינו מכיל המלצות, תחזיות או מידע אישי.

## שיטה
* **פרוקסי סקטור** (כשאין קרן סקטור ייעודית): סל של עד 30 המניות הגדולות בסקטור בקרן המקור, במשקלים הנוכחיים (קבועים, איזון יומי), מחירים מ-Yahoo **מומרים לדולר**. מוצג מול קו השוק בדולר (המדד ÷ שער החליפין, או קרן הסל). אינו מדד רשמי; ההרכב הנוכחי מוחל על העבר (הטיית שורדים). אחוז הכיסוי מוצג.
* **תשואות** — שינוי מחיר מצטבר; תנודתיות = סטיית תקן יומית בשנה האחרונה × √252; ירידה מקסימלית בשנה האחרונה.
* כל נתון שלא נמצא מוצג כ"לא זמין", והסיבה מפורטת בסעיף "מקורות, שיטה ופערים" של כל שוק.

## מגבלות ידועות
* **קזחסטן** — אין מדד KASE ב-Yahoo ואין קרן סל מדינה עם פילוח ציבורי; מוצג שער KZT בלבד.
* **שווקים גבוליים** — XSFD היא קרן סינתטית; סל הבטוחות שמפורסם אינו משקף את המדד, ולכן אין פילוח סקטורים.
* מדדים שאינם זמינים ב-Yahoo (למשל IPSA בצ'ילה, S&P/BVL בפרו, SET בתאילנד, WIG20 בפולין) מוחלפים בקרן סל המדינה.
* הנקודה האחרונה בגרף עשויה להיות מחיר תוך-יומי.
